API 文档

Relay 兼容 OpenAI Chat Completions 协议：把 baseURL 指向 https://relay.zmzai.cloud/v1，用 API Key 鉴权即可。zcode、codex 等第三方工具直接使用此地址。模型与价格见 模型列表。

鉴权 非流式请求 流式请求 渠道路由 推理强度 计费 上游异常与重试

01鉴权

在控制台创建 API Key 后，通过 Authorization: Bearer <YOUR_API_KEY> 请求头传入。Key 可随时吊销，每次调用按 token 实时计费。

02非流式请求

curl — 非流式
curl https://relay.zmzai.cloud/v1/chat/completions \
  -H "Authorization: Bearer " \
  -H "Content-Type: application/json" \
  -d '{"model":"YOUR_MODEL_ID","messages":[{"role":"user","content":"你好"}]}'

03流式请求

请求体增加 "stream": true，服务端返回 SSE 数据流，末尾的 usage 事件携带本次调用的 token 统计。

curl — 流式
curl -N https://relay.zmzai.cloud/v1/chat/completions \
  -H "Authorization: Bearer " \
  -H "Content-Type: application/json" \
  -d '{"model":"YOUR_MODEL_ID","stream":true,"messages":[{"role":"user","content":"你好"}]}'

04渠道路由

默认按模型自动选择上游渠道，失败时尝试其他可用渠道。价格按最终使用的渠道计算，不同渠道的价格可能不同；需要固定渠道时，在请求体传入 "channel": "渠道名"。

05推理强度

支持 reasoning_effort 参数（low / medium / high，各模型支持范围见模型详情页）。

06计费

按 token 计费：输入、输出分别计价，缓存价格未单独配置时按输入价结算。调用前按预估用量预占额度，结束后按实际用量和所用渠道价格结算；余额与每笔账单可在控制台「账单」核对。

无用量返回的流式请求不计费：此类调用记为「待结算」并释放预占余额。

07上游异常与重试

上游短时限流返回 UPSTREAM_RATE_LIMITED；周/月额度用尽返回 UPSTREAM_QUOTA_EXHAUSTED；上游余额或鉴权异常分别返回 UPSTREAM_BALANCE 和 UPSTREAM_AUTH。

如响应包含 Retry-After，请等待指定秒数后再试；该时间只是下次尝试时间，并不保证上游已恢复。
